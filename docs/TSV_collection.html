Literary analysis: adjectives in boss fight dialogue

This collection, made in Cytoscape, looks at the adjectives used in different bosses dialogue in the fights.

To do this analysis I used a JSON file I sourced from the Elden Ring Text Explorer which is beautifly made. This page will talk about what I noticed and how I did my literary analysis.

The JSON file

This example may be long, but it's important that its so long; each of the numbers, like 3010010 and 3010020, are scene blocks. These scene blocks seperate each string of dialog and allowed for me to seperate it using XSLT.
The dialog JSON had to be formated first using an XSLT transformation, which was then put through a python script that seperated based on what boss it is. These files were put into folders where they can be easily grabbed.

You can see the raw files for the XSLT that structured the JSON file and the jupyter notebook that grabed the adjectives out of the dialogue into a TSV file that could be used in Cytoscape.

Cyotscape Networks

Here we can finally look at the cytoscape networks that I made with my boss fight adjectives!

This frist collection focuses on all the data I pulled from all the boss fights, a lot of the words are conected to many characters at once.
Youll also notice that there are repeats of the same character in the network, this is the different scene blocks for each character.

Rennala has the most words associated with just one scene out of all the dialog I pulled. Her words are etheral sounding, as her purpose in game is to birth the player anew.

Godrick is the most talkitive in his boss fight, as he has the most words associated with him and his many scenes. His theme is more treating the player as unfit for Elden Lord and how he as an Omen will take the player down.

The next couple of collections are not as interesting data wise, they have very little words associated with them, and they have a generic theme of just calling the player undeserving of the throne.

Even though its I wasn't able to find a theme with Malikeths words, he does have the least out of everyone.
